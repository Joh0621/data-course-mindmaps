# 复杂数据的整理方法
- 相关分析：关系类型
  - 基本概念
    - 函数关系：确定性关系
    - 相关关系：非确定性的相互依存关系
  - 分类维度
    - 因素数量：单相关、复相关
    - 变化方向：正相关、负相关
    - 相关程度：完全相关、不完全相关、不相关
    - 图形：正线性、负线性、曲线、不相关
- 相关分析：相关系数 r
  - 取值与方向
    - −1 ≤ r ≤ 1
    - r＞0 为正相关；r＜0 为负相关
  - 强弱判断
    - |r| 越接近1，线性关系越强
    - |r|＝1：完全线性相关
    - r＝0：无线性相关，仍可能有非线性关系
- 相关分析：Excel案例
  - 分析流程
    - 录入月访问量与月营业额
    - 插入 → 散点图，观察关系
    - 文件 → 选项 → 加载项 → 分析工具库
    - 数据 → 数据分析 → 相关系数
    - 选输入区域、分组方式、首行标签与输出位置
  - 结果解读
    - r≈0.999835：极强的正线性相关
    - 相关程度很高，本身不能证明因果关系【补充】
- 回归分析：模型与含义
  - 目标
    - 用已知或设定的自变量值，估计因变量均值
    - 在关系分析基础上建立模型，用于预测
  - 一元线性模型
    - Yᵢ＝β₀＋β₁Xᵢ＋μᵢ
    - X：自变量；Y：因变量
    - β₀：截距；β₁：斜率；μᵢ：随机误差
  - 随机误差来源
    - 未知因素、残缺数据、众多细小因素
    - 观测误差、模型设定误差、内在随机性
- 回归分析：步骤与案例
  - 五步流程
    - ① 确定自变量与因变量
    - ② 画散点图，判断模型类型
    - ③ 建模，用最小二乘法估计参数
    - ④ 检验模型
    - ⑤ 代入模型进行预测
  - 纯收入 → 消费支出
    - X＝人均纯收入；Y＝人均消费支出
    - 课件方程：ŷ＝7.8940＋0.7374x
    - 收入增加100元，对应预测消费增加73.74元
    - F＝214.13＞5.99（α＝0.05），线性关系显著
    - x＝3500：按所列方程计算 ŷ≈2588.79元
    - 课件写2588.72元，与所列方程有小出入
- 相关与回归：辨析
  - 变量地位
    - 相关：X、Y地位对称
    - 回归：区分解释变量X与被解释变量Y
  - 分析目的
    - 相关：描述关系的方向与密切程度
    - 回归：建立数量关系，估计与预测
  - 理解边界
    - 经典回归可把X视为给定；不宜泛化为X只能非随机【补充】
    - 回归关系本身也不能自动证明因果【补充】
