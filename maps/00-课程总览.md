# 数据整理课程
- 课程一｜数据整理
  - 基础流程：设计 → 审核 → 分组汇总 → 展示 → 归档
  - 统计分组：组内同质、组间差异；穷尽与互斥
  - 分组方法：品质 / 数量；平行 / 复合
  - 分配数列：品质、单项、组距
  - 整理规范：真实、一致、可靠
- 课程二｜简单数据
  - 直方图：看分布、看波动、定位改进重点
  - 绘制：极差 → 组数 → 组距 → 组界 → 频数 → 图形
  - 形态分析：正常、折齿、缓坡、孤岛、双峰、绝壁
  - 分组整理：选标志、划界限
  - 层别整理：按来源分类，以人机物法环排查原因
- 课程三｜复杂数据
  - 相关分析：判断关系方向与强弱
  - 相关系数：−1≤r≤1；看符号与绝对值
  - Excel案例：访问量与营业额 r≈0.999835
  - 回归分析：建模 → 估参 → 检验 → 预测
  - 一元模型：Yᵢ＝β₀＋β₁Xᵢ＋μᵢ
  - 辨析：相关看密切程度，回归估计数量关系
