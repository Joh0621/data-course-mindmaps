# 课堂课程思维导图

按 bb 文件夹内五组课程截图逐页整理，保留每页识别文字；图表节点仅展示从课件图表区域裁出的图片。

网页编辑会保存在当前浏览器。导出 JSON 可备份与导入，FreeMind 格式可在兼容软件中继续编辑。

GitHub Pages: main branch, root directory.

## XMind 源文件（`xmind/` 目录）

课程一～课程十的 XMind 文件，可直接用 XMind 打开继续编辑。

| 文件 | 状态 | 大小 |
| --- | --- | --- |
| 课程一～课程五-可编辑思维导图-逐字待核.xmind | 可编辑导图，逐字校对未完成 | 约 14.6 MB / 个 |
| 课程六～课程十-原图底稿-文字待整理.xmind | 原图底稿，文字待整理 | 约 1.4–3.4 MB / 个 |

`截图与待核情况.txt` 记录了各课程截图节点的核对进度与已知待核位置（遮挡、截断、小字等）。

说明：大文件直接存放于仓库，克隆时体积较大；仅需网页版导图时可忽略 `xmind/` 目录。
